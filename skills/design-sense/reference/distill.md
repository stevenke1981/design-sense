# `distill`

**When:** Too many elements, options or steps; strip to the essence.

## Steps
1. List every element and ask: what breaks if this is gone?
2. Remove, then merge, then hide behind progressive disclosure — in that order.
3. Cut copy by half; keep verbs and numbers.
4. Collapse settings into sensible defaults.
5. Re-check that each remaining element has one job.

## Checks before you finish
- [ ] Primary task takes fewer steps
- [ ] Nothing essential became hard to find
- [ ] `design-sense check` run on changed files; P0–P2 fixed or explained

## Do
- Show the user what you removed and why

## Don't
- Hide important actions in overflow menus just to look clean
