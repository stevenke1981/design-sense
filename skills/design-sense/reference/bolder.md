# `bolder`

**When:** The design is safe, bland or forgettable and the user wants more presence.

## Steps
1. Find the one thing that should be remembered (headline, product shot, number).
2. Increase scale contrast: make the focal element much larger and the rest calmer.
3. Commit to one strong color move (a saturated accent field, or a dark section) instead of many small ones.
4. Use a more characterful typeface for display text (keep body readable).
5. Replace decoration with real content: screenshots, data, photography.

## Checks before you finish
- [ ] Still one clear primary action
- [ ] Contrast and readability not sacrificed
- [ ] Brand constraints respected
- [ ] `design-sense check` run on changed files; P0–P2 fixed or explained

## Do
- Use asymmetry and white space deliberately

## Don't
- Add gradients, glows, glass and emoji — that is louder, not bolder
