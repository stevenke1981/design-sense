# `clarify`

**When:** Labels, microcopy, errors or instructions are confusing.

## Steps
1. Use the user's words for things; one name per concept everywhere.
2. Buttons are verbs describing the result ('儲存變更', 'Export PNG'), not 'OK'.
3. Errors: what happened + why + how to fix, in plain language.
4. zh-TW: Taiwan terms (檔案, 設定, 資料夾, 軟體, 預設, 影片), full-width punctuation, space between CJK and Latin/numbers is optional but consistent.
5. Remove hype and filler words.

## Checks before you finish
- [ ] `slop/hype-copy` clean
- [ ] No two labels for one action
- [ ] `design-sense check` run on changed files; P0–P2 fixed or explained

## Do
- Read labels aloud in context

## Don't
- Use Mainland terms (文件夾, 軟件, 默認, 視頻) in zh-TW products
