# `quieter`

**When:** The design is loud, busy or tiring.

## Steps
1. Count accents; reduce to one accent color and one emphasis style.
2. Remove borders/shadows where spacing alone separates content.
3. Lower saturation of large areas; keep saturation for small, important things.
4. Reduce motion to state changes only.
5. Merge redundant labels/badges/icons.

## Checks before you finish
- [ ] Hierarchy still clear after removal
- [ ] Primary action still obvious
- [ ] `design-sense check` run on changed files; P0–P2 fixed or explained

## Do
- Remove before you restyle

## Don't
- Make everything gray — quiet is not lifeless
